MINECRAFT BEDROCK FAMILY

Install the CLI:
  pipx install minecraft-bedrock-family
  bedrock-family init ~/MinecraftFamily
  cd ~/MinecraftFamily
  bedrock-family setup --accept-eula

Full help: bedrock-family --help. The CLI follows the terminal's language preferences.
Choose a language for one command: bedrock-family --language fr --help.
Set it for the terminal session: export BEDROCK_FAMILY_LANGUAGE=fr (or en).
Run the commands below from the server folder.

SERVER AND GAMES
  bedrock-family server start
    Start without scheduling a stop.
  bedrock-family session start
    Start and schedule the usual finishing time.
  bedrock-family session start --until 21:00
    Choose a finishing time for this game only.
  bedrock-family session status
    Check the planned time and timer.
  bedrock-family session cancel
    Cancel the timer without stopping.
  bedrock-family session stop
    Stop now, back up and leave the server off.
  bedrock-family session logs
    Read shutdown and backup messages.
  bedrock-family server stop
    Stop without an automatic backup.
  bedrock-family server restart
    Restart while keeping world files.
  bedrock-family server down
    Remove containers; keep the world.
  bedrock-family server status
    See the server state.
  bedrock-family server logs [--once] [--tail 100]
    Follow messages or show them once.
  bedrock-family server console "say Hello"
    Send a game command.

FINISHING TIME
  bedrock-family session default show
    Show the usual time.
  bedrock-family session default set 20:30
    Save a new usual time.
  bedrock-family session default reset
    Return to 19:00.

WORLDS
  bedrock-family world list
    Show available worlds and the default.
  bedrock-family world use "World Name"
    Choose an existing world for the next start.
  bedrock-family world create "New World"
    Create and start a new world.
    If a server is running, confirm its restart with --yes.

GAME RULES
  bedrock-family settings show
    Show saved rules and the usual finishing time.
  bedrock-family settings set cheats off
    Enable or disable cheats: on or off.
  bedrock-family settings set keep-inventory on
    Keep inventory after death: on or off.
  bedrock-family settings set difficulty easy
    peaceful, easy, normal or hard.
  bedrock-family settings set sleep 50
    Sleeping-player percentage: 0 to 100.
  bedrock-family settings set sleep-one
    One player in bed is enough.
  bedrock-family settings set gamemode survival
    Default mode: survival, creative or adventure.
  bedrock-family settings set finish-time 20:30
    Set the usual finishing time.
  bedrock-family players set-mode creative
    Change connected players only.
  bedrock-family settings apply
    Start and apply saved rules.
  bedrock-family settings reset
    Restore family game-rule defaults.

PLAYERS AND ACCESS
  bedrock-family players list
    Show who is connected.
  bedrock-family players xuids
    Find player IDs in retained messages.
  bedrock-family access preview
    Show connected players without changing the list.
  bedrock-family access sync
    Enroll connected players; keep absent enrolled players.
  bedrock-family access show
    Show enrolled players.
  bedrock-family access enable
    Restrict admission to enrolled players.
  bedrock-family access disable --confirm
    Temporarily open admission.
  bedrock-family access remove "Player Name"
    Remove a name or XUID; keep their builds.
  bedrock-family access edit
    Edit the list manually.
  bedrock-family access reload
    Validate and reload the edited list.

BACKUPS
  bedrock-family backup create
    Back up, then restore the initial running/stopped state.
  bedrock-family backup list
    List archives.
  bedrock-family backup restore "backups/archive.tar.gz" --confirm
    Restore a world; keep current settings and access.
  bedrock-family open backups
    Open the backup folder.

MAINTENANCE
  bedrock-family init [FOLDER]
    Create or adopt a server folder without overwriting existing files.
  bedrock-family setup [--accept-eula] [--ip ADDRESS]
    Accept the terms and detect or choose the IPv4 address.
  bedrock-family check
    Validate configuration.
  bedrock-family doctor
    Check Docker and the environment.
  bedrock-family update
    Back up and update using the saved version choice.
  bedrock-family update --server
    Back up and download the latest Bedrock server.
  bedrock-family version pin
    Keep the downloaded version on future starts.
  bedrock-family version pull
    Download only the Docker image.
  bedrock-family open data
    Open world data; do not delete this folder.
  bedrock-family open settings
    Edit advanced server settings.
  bedrock-family open network
    Edit the server address and version.

Cheats are enabled by default and disable world achievements.
Sleep at 0 percent still needs one player in bed.
Make commands are reserved for tests and contributions.
